# Changelog

## 2.0

- Log drinks with 16 duotone appearances and 20 editable presets.
- Use a separate caffeine status key or combine drink and status on one key.
- Choose caffeine, sleep estimate, both estimates or a status face on each status key.
- Tap a status key to see its alternate display for five seconds, or press again to return sooner.
- Follow estimated caffeine remaining with five static faces using the same colour bands as the number.
- Show estimated caffeine remaining with changing colours and an optional sleep estimate.
- See today's drink count on each key, with a three-second confirmation after logging.
- Add missed drinks, correct timestamps and delete entries in the shared history.
- Customize bedtime, time format, caffeine half-life and sleep threshold.
- Keep existing drink names and caffeine amounts when updating.
- Avoid unnecessary settings writes while idle and correctly recognize taps during startup.
- Improve keyboard navigation and handling of pending history saves and disconnections.
- Update the WebSocket dependency to include its published security fixes.
- Refresh the plugin artwork.

Requires Stream Deck 6.9+, macOS 13+ or Windows 11 (64-bit).
